# AIDA2 自由潜学习舱

一个面向 AIDA2 自由潜水理论复习的中文静态学习网页。项目将课程知识整理为章节学习、随堂检查和模拟考试，适合在电脑或手机浏览器中使用。

在线访问：<https://xspmt.github.io/aida2-study/>

## 主要功能

- 10 个理论学习章节，覆盖呼吸、生理、压力平衡、潜水技术、安全机制、装备、自由潜项目和行为准则等内容。
- 每章配有随堂检查，可用于确认知识点掌握情况。
- 支持搜索耳压、BO、装备等课程知识点。
- 提供 33 题、总分 100 分的模拟考试。
- 支持单选、多选、填空、列举、排序和匹配题。
- 提交试卷后自动判分，并显示错题说明和复习要点。
- 提供原始理论手册和试卷 PDF 的在线入口。
- 适配电脑和手机屏幕。

## 学习进度与隐私

章节进度、随堂测验、考试答案和最高分通过浏览器的 `localStorage` 保存在本机，不会上传到 GitHub 或其他服务器。

- 刷新或重新打开网页后，记录通常仍然保留。
- 更换手机、电脑或浏览器后，记录不会自动同步。
- 无痕模式可能不会长期保留记录。
- 清理浏览器网站数据或点击网页中的“重置进度”会删除记录。
- 其他访问者无法看到你的学习进度和答题内容。

## 使用方法

1. 打开在线学习网页。
2. 按章节阅读理论并完成每章随堂检查。
3. 使用顶部搜索框快速查找知识点。
4. 完成复习后进入“模拟考试”，提交整卷并查看解析。
5. 手机端可点击左上角菜单切换章节或打开 PDF。

如果微信内置浏览器不能正常预览 PDF，请选择“在浏览器打开”，使用 Safari、Chrome 或手机系统浏览器查看。

## 本地运行

项目不需要安装依赖或构建工具。由于浏览器可能限制直接打开本地文件，建议在项目目录启动一个静态文件服务器：

```powershell
python -m http.server 8000
```

然后访问：<http://127.0.0.1:8000/>

也可以使用其他静态文件服务器部署。

## 安全提示

自由潜水存在低氧昏迷、耳压伤害和溺水等风险。任何水中闭气训练都必须由具备能力的潜伴进行一对一看护，不要独自训练，不要超呼吸，也不要仅根据网页内容自行尝试救援或深度训练。实际操作应由合格教练现场指导。
